# Style Shift Web Pages

Public website and legal pages for the Style Shift Android application.

- Website: https://durdenk.github.io/style-shift-web/
- Privacy policy: https://durdenk.github.io/style-shift-web/privacy-policy.html
- Terms of use: https://durdenk.github.io/style-shift-web/terms-of-use.html
- Authorized seller declaration: https://durdenk.github.io/style-shift-web/app-ads.txt
- Google Play package: `com.cukkacreatives.styleshift`

## Publishing

Copy the contents of this directory to the root of the `durdenk/style-shift-web` repository and publish its `main` branch with GitHub Pages.

Keep `app-ads.txt` at the root of the published site so advertising systems can discover it. Update the privacy policy and terms whenever the app’s permissions, SDKs, backend, data retention, or data recipients change.
